# 🌏 GHURI Bangladesh
### Discover Bangladesh. Plan with Confidence. Travel with Ease.

**A Unified Digital Travel Companion for Exploring Bangladesh**

GHURI Bangladesh is an all-in-one digital travel companion designed to make discovering and exploring Bangladesh easier, smarter, and more accessible. It brings destination discovery, interactive maps, transportation information, budget estimation, nearby services, and personalised trip planning together in one platform.

Our goal is simple: make exploring Bangladesh less complicated and more rewarding.

---

## ✨ About the Project

Bangladesh is home to breathtaking landscapes, diverse cultures, historical landmarks, beautiful coastlines, tea gardens, forests, rivers, and countless hidden destinations.

Yet, planning a trip across the country can be challenging. Travel information is often scattered across different websites, social media platforms, and local sources. Travellers may struggle to find useful destination information, understand transportation options, estimate expenses, locate nearby services, and organise their journeys.

**GHURI Bangladesh aims to bring these essential travel resources together in one convenient platform.**

Currently featuring **48 destinations across all 8 divisions of Bangladesh**, GHURI helps users discover places, explore travel information, navigate locations, estimate trip expenses, and organise personalised itineraries.

Whether someone is exploring Bangladesh for the first time or discovering somewhere new within their own country, GHURI aims to make the journey easier to plan.

---

## 🎯 The Problem We're Solving

Planning a trip should be exciting, not overwhelming.

However, travellers often face challenges such as:

- Fragmented travel information across multiple platforms.
- Difficulty discovering destinations beyond popular tourist attractions.
- Limited access to organised destination information.
- Uncertainty about transportation routes, travel times, and estimated costs.
- Difficulty identifying nearby services and useful facilities.
- Complicated budget planning and itinerary organisation.
- Language barriers for international visitors and local travellers.

GHURI addresses these challenges through a unified, accessible, and user-friendly travel platform.

## 🚀 Key Features

### 1. 🧭 Discover Bangladesh
Explore destinations across all eight administrative divisions of Bangladesh.

- Currently featuring 48 destinations.
- Destination-specific photographs and information.
- Search and filter destinations.
- Browse by division, district, category, season, and trip type.
- Discover popular attractions and lesser-known places.

### 2. 🗺️ Interactive Map
Explore destinations geographically and understand where places are located.

- Map-based destination exploration.
- Location markers and geographical information.
- Explore destinations across Bangladesh.
- Access location and route information.

### 3. 🚗 Route Finder
Find travel routes and explore available transportation options.

- Select origin and destination.
- Explore road routes.
- View available transportation information.
- Check estimated travel distances and durations where supported.
- Understand transportation-related cost estimates where available.

*Transportation information and estimates may vary depending on route availability and data sources.*

### 4. 📍 Nearby Services
Discover useful services around travel destinations.

- Explore nearby facilities.
- Find relevant local services.
- Access location-based information.

### 5. 🧳 Smart Trip Planner
Organise trips through a personalised planning experience.

- Select destinations.
- Choose travel dates and trip duration.
- Specify the number of travellers.
- Select preferred transportation options.
- Set travel preferences and budget.
- Generate organised travel itineraries.

### 6. 💰 Budget Estimator
Get a better understanding of potential travel expenses before starting a journey.

- Estimate transportation expenses.
- Plan accommodation and other trip costs where supported.
- Explore estimated trip budgets.
- Organise expenses according to travel preferences.

*Displayed costs are estimates unless explicitly identified as verified fares or prices.*

### 7. 🌐 Bilingual Experience
GHURI aims to make travel information accessible to a wider audience.

- English language support.
- Bangla language support.
- Language switching throughout the application.

## 🏗️ Getting Started

Follow these instructions to run GHURI locally.

### Prerequisites

Make sure you have installed:

- Node.js (LTS recommended)
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/maliha-tabassum-hridila/ghuri-bangladesh.git
```

### 2. Navigate to the project directory

```bash
cd ghuri-bangladesh
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Visit the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```

### 6. Create a production build

```bash
npm run build
```

The production-ready files will be generated in the `dist` directory.
